Analytical Three-Phase Motor Model and Graphical UI

A Python-based calculator + UI for constructing three-phase permanent magnet motors using PyQt5. An analytical model for determining performance (torque, current density) from winding characteristics, stator/rotor geometry, magnetic flux, and correction factors. Ran a Finite Element Magnetics simulation to get +/-5% error on KV, Kt, peak torque, flux linkage.
- Allows for inrunner/outrunner and slot/pole count configurations
- Allows for selection of plastic or metal rotor ring for prototyping purposes.
- Calculates airgap flux density while accounting for airgap length, Carter coefficients, slot leakage, temperature remanence derating, magnetic permeability,
- Accounts for neodymium magnet grade and geometry
- Accounts for stator tooth/slot geometry, thickness, and material
- Accounts for series/parallel winding paths, star/delta connections, internal parallel strands for insulated copper windings, buildup, and turns per tooth.
- Accounts for magnet skew, winding pitch, and distribution factors for both concentrated and distributed windings.
- 5% error in KV, Kt, peak torque, and flux linkage from identical numerical simulations using FEMM

Pneumatic Soft-Actuated Hand

This is my air-powered McKibben soft robotic hand designed to mimic hand bones, up to 12 hand muscles, and tendon systems found in the actual hand.

It features a self-topping compressor-accumulator tank controlled via N-Ch MOSFET + 12V Bosch automotive relay + 12V pressure transducer for hysteresis control via a cheap ESP32 board, using C++/PlatformIO.

At the time, I was dealing with some deep hand injuries from handbalancing training, so it was a good visualizer for my self-rehab.

  • Actuator Type Custom McKibben (balloon + 1.25in. braided harness)
  • Voltage 12V Power -> 5V Logic (LM2596)
  • Number of Actuators Up to 12
  • Pressure Control Type Tire Pump + Pressure Transducer
  • Hysteresis Control Hardware Bosch Relay + MOSFET
  • Actuation Control I2C PWM -> transistor array -> Solenoid valve
  • Status V1 Concept Complete
